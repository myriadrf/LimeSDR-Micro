Overview
########

One of the key elements of the LimeSDR Micro mPCIe board is the NXP `LA9310S7S11AA`_ baseband processor. 
Its main function is to transfer digital data between the LMS7002M RF transceiver and the host computer through the mPCIe edge connector.
