A key feature of LimeSDR Micro is that it integrates an NXP LA9310 baseband processor, which may be used to offload baseband processing from the host computer. This might be used to implement part of or a complete PHY layer, or to accelerate general signal processing tasks.

This guide is concerned with LA9310 firmware development and will be expanded over time to include more resources, and examples.

.. note::
   For information regarding developing host applications please refer to the :external+suiteng:ref:`Lime Suite NG documentation <index:introduction>`.
