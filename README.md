# LimeSDR Micro

LimeSDR Micro is an SDR board available in M.2 (2280 B+M key) and mPCIe versions, combining the NXP LA9310 baseband processor with the Lime Microsystems LMS7002M RF transceiver.

## Contents

The hardware design files are available for [M.2](https://github.com/myriadrf/LimeSDR-Micro/tree/main/hardware/M.2) and [mPCIe](https://github.com/myriadrf/LimeSDR-Micro/tree/main/hardware/mPCIe).

The directory structure is as follows:

      hardware/M.2/<version>/
          OutputJobs/            - Output jobs
          PCB/                   - PCB design
          Project Outputs for <project>/ - BOM, rule check reports, Gerbers, pick & place files, PDFs
          Schematics/            - Schematic diagrams

      hardware/mPCIe/<version>/
          OutputJobs/            - Output jobs
          PCB/                   - PCB design
          Project Outputs for <project>/ - BOM, rule check reports, Gerbers, pick & place files, PDFs
          Schematics/            - Schematic diagrams
